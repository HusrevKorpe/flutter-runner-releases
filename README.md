# Flutter Runner

Android Studio ya da VS Code açmadan Flutter uygulamasını simülatörde
çalıştıran macOS menü çubuğu aracı: Run, Hot Reload, Restart, Stop, DevTools.

## Kurulum

Terminale yapıştır:

```bash
curl -fsSL https://github.com/HusrevKorpe/flutter-runner-releases/releases/latest/download/install.sh | bash
```

Uygulama menü çubuğuna (saatin yanına) yerleşir. Sonraki güncellemeler
uygulamanın içinden gelir.

Gereken: macOS 15 veya üstü, kurulu Flutter.
